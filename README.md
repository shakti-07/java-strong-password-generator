# 🔐 Strong Password Generator

A simple Java-based Strong Password Generator that creates random and secure passwords to help users improve their online security.

## 🚀 Features

- Generates random passwords.
- Allows users to generate strong passwords.
- Uses a combination of different character types.
- Simple and easy-to-use interface.
- Helps create passwords that are difficult to guess.

## 🛠️ Technologies Used

Technologies
- Java
- Java Math / SecureRandom
- Arrays, loops, methods and Strings
